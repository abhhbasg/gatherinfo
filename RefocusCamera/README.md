# 后对焦 · RefocusCamera

一款 iOS 相机：**先拍摄，后对焦**。界面采用 iOS 26 的液态玻璃（Liquid Glass）设计。

## 原理

按下快门后，相机锁定曝光和白平衡，把镜头从最近对焦距离逐步推到无穷远，
在每个位置拍一张照片（5 / 9 / 15 帧可选），组成一个**焦点堆栈**；中间那一帧还会附带深度（视差）数据。

拍完后在编辑器中：

| 操作 | 实现 |
| --- | --- |
| 点按画面任意位置重新对焦 | 每帧按 16×16 网格计算拉普拉斯清晰度，选出该处最清晰的那一帧，交叉淡入 |
| 拖动“焦平面”滑块 | 由近到远浏览每一帧 |
| 全景深 | 每个区域取最清晰的帧，羽化遮罩后合成（焦点堆叠） |
| 光圈 ƒ/16 → ƒ/1.4 | 用深度图生成遮罩，按与对焦点的视差差值做可变模糊（`CIMaskedVariableBlur`） |
| 存储 | 以全分辨率合成 HEIF，写入“照片” |

对焦时镜头会“呼吸”（视角轻微缩放），所以每帧先用 Vision 的单应性配准（`VNHomographicImageRegistrationRequest`）对齐到基准帧。

## 拍摄模式

取景框下方的液态玻璃选择器（或在取景框上左右滑动）可以切换 5 种模式；点按左上角的模式标签可查看对比说明。

| 模式 | 文件 | 锐化 | 降噪 | 多帧合成 | 深度 / 虚化 | 镜头 |
| --- | --- | --- | --- | --- | --- | --- |
| 智能 | HEIC | 强 | 强 | 是 | 有 | 双摄 / LiDAR |
| 少处理 | HEIC | 有 | 有 | 否（`.speed`，关闭多摄融合与畸变校正） | 有 | 双摄 / LiDAR |
| ProRAW | DNG | 系统未公开；App 显影时不再锐化 | 有 | 是 | 无 | 双摄 / LiDAR |
| RAW | DNG（Bayer） | **无** | 仅色度 | 否 | 无 | 广角 |
| 高速 | HEIC（视频帧） | 有 | 有 | 否 | 无 | 广角 |

- **RAW** 是唯一完全不锐化的模式：传感器原始数据，在 App 内用 `CIRAWFilter` 显影，
  关闭锐化、细节增强、亮度降噪和局部色调映射（保留默认色度降噪）。
- **高速** 从视频流抓帧，每抓到一帧就立刻把镜头推向下一个位置，12–36 层焦平面在一秒左右扫完，适合手持；
  分辨率取决于当前视频格式。
- 设备不支持的模式（例如没有 ProRAW 的机型）切换失败后会自动回退，并在选择器中划掉。
- 编辑 RAW / ProRAW 堆栈时，长按“存储”可以把当前焦平面的**原始 DNG** 存进“照片”。

## 滤镜与质感

编辑器底部的液态玻璃标签栏分为 **对焦 / 滤镜 / 调整 / 水印** 四页。处理顺序为：对焦 → 景深虚化 → 调色 → 质感 → 水印。

**12 款原创预设**（可调强度）：原片、暖阳 400、青柠、银盐、高反差黑白、褪色胶片、电影、夜霓虹、柔雾、复古、冷调、浓郁。

**20 项调整**（在预设之上叠加，刻度拨盘调节，双击拨盘归零）：

| 分组 | 项目 |
| --- | --- |
| 光影 | 曝光、对比度、高光、阴影、胶片 S 曲线、褪色（抬黑） |
| 色彩 | 色温、色调、饱和度、自然饱和度、黑白、分离色调 |
| 细节 | 清晰度（局部对比）、锐化（默认关闭） |
| 质感 | 颗粒、颗粒大小、暗角、光晕（高光红晕）、柔雾、漏光 |

- 色调与色彩在 sRGB 伽马空间里计算，模糊类光学效果（光晕、柔雾）在线性空间里计算。
- 所有半径和颗粒尺寸按图像宽度换算，所以预览和全分辨率导出看起来一致。
- 长按画面可以对比原图。

## 水印

| 样式 | 说明 |
| --- | --- |
| 参数底栏 | 照片下方的白 / 黑底栏：左侧机型与日期，右侧焦距、光圈、快门、ISO 与署名 |
| 画廊 | 四周留白，下方居中排版，像影展作品 |
| 胶片边框 | 黑色片边、片孔、琥珀色片边编号，照片右下角带辉光的日期印字 |
| 相纸 | 宽下边的相纸，斜体题字 |
| 签名 | 照片右下角的斜体署名与等宽参数 |
| 取景器 | 四角框线、对焦框（标出你点按的位置）和等宽数据 |

- 拍摄参数优先读取照片 EXIF；视频帧没有 EXIF，用拍摄时记录的 ISO、快门、光圈和等效焦距补全。
- 可选显示机型、参数、日期，可设置署名、字体（无衬线 / 衬线 / 等宽 / 圆体）和边框颜色；署名与字体会被记住。

## 动效

- 模式选择器的高亮胶囊在选项间弹性流动，配合选择触感
- 规格栏的数值从下方推入，颜色标示处理轻重
- 切换镜头时取景框模糊遮盖并轻微收缩，避免画面跳变
- 扫描时快门内圈收缩、进度环推进，每一帧都有轻触感；完成时闪白并给出成功触感
- 编辑器从缩略图缩放展开（关闭时缩回），分析期间显示模糊预览与进度环
- 重新对焦时旧画面逐渐失焦、新画面浮现，模拟“拉焦”
- 编辑器标签栏的高亮胶囊流动、图标弹跳；切换面板时内容上浮淡入，画面区域随面板高度平滑伸缩
- 刻度拨盘随拖动滚动、每格一次触感，归零时刻度平滑滚回；工具按钮外圈弧线实时显示数值

## 目录

```
RefocusCamera/
├── App/            应用入口
├── Camera/         AVFoundation 会话、焦平面扫描、实时预览
├── Processing/     对齐、清晰度分析、深度、合成渲染
├── Library/        堆栈的本地存储（Documents/FocusStacks）
└── Views/          液态玻璃界面：取景、编辑器、图库
```

## 运行

- Xcode 26 或更新版本，iOS 26 真机（模拟器没有相机）
- 打开 `RefocusCamera.xcodeproj`，在 *Signing & Capabilities* 选择你的开发团队，必要时修改 Bundle ID
- 带双摄 / LiDAR 的机型可获得深度数据并启用“光圈”虚化；只有单摄的机型仍可使用焦点堆栈

## 注意

- 扫描 9 帧大约需要 1 秒，拍摄时请保持手机稳定（对齐能纠正轻微抖动，无法纠正明显的运动物体）
- 如果设备的虚拟多摄不允许手动设置镜头位置，会退回到广角镜头（此时没有深度数据）
