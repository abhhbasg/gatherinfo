# 后对焦 · RefocusCamera

一款 iOS 相机：**先拍摄，后对焦**。界面采用 iOS 26 的液态玻璃（Liquid Glass）设计。

## 原理

按下快门后，相机锁定曝光和白平衡，把镜头从最近对焦距离逐步推到无穷远，
在每个位置拍一张照片（5 / 9 / 15 帧可选），组成一个**焦点堆栈**；中间那一帧还会附带深度（视差）数据。

拍完后在编辑器中：

| 操作 | 实现 |
| --- | --- |
| 点按画面任意位置重新对焦 | 每帧按 16×16 网格计算拉普拉斯清晰度，选出该处最清晰的那一帧，交叉淡入 |
| 拖动“焦平面”滑块 | 由近到远浏览每一帧 |
| 全景深 | 每个区域取最清晰的帧，羽化遮罩后合成（焦点堆叠） |
| 光圈 ƒ/16 → ƒ/1.4 | 用深度图生成遮罩，按与对焦点的视差差值做可变模糊（`CIMaskedVariableBlur`） |
| 存储 | 以全分辨率合成 HEIF，写入“照片” |

对焦时镜头会“呼吸”（视角轻微缩放），所以每帧先用 Vision 的单应性配准（`VNHomographicImageRegistrationRequest`）对齐到基准帧。

## 关闭计算摄影（RAW）

取景界面左上角的开关可在两种格式之间切换：

| | 计算摄影（默认） | RAW |
| --- | --- | --- |
| 文件 | HEIC | Bayer RAW（DNG） |
| 系统处理 | Deep Fusion、Smart HDR、多帧降噪、语义渲染、锐化 | 无 —— 直接来自传感器 |
| 镜头 | 双摄 / LiDAR 虚拟设备 | 广角物理镜头（Bayer RAW 只能由物理镜头输出） |
| 深度与光圈虚化 | 有 | 无 |

- 不使用 Apple ProRAW：它本身是多帧合成的“计算 RAW”。
- RAW 在 App 内用 `CIRAWFilter` 显影：只做去马赛克、白平衡、镜头校正和全局色调曲线，
  关闭锐化、细节增强、亮度降噪和局部色调映射（保留了默认的色度降噪，否则高 ISO 下彩色噪点很重）。
- 编辑 RAW 堆栈时，长按“存储”可以把当前焦平面那一帧的**原始 DNG** 存进“照片”，在其他软件里自行显影。

## 目录

```
RefocusCamera/
├── App/            应用入口
├── Camera/         AVFoundation 会话、焦平面扫描、实时预览
├── Processing/     对齐、清晰度分析、深度、合成渲染
├── Library/        堆栈的本地存储（Documents/FocusStacks）
└── Views/          液态玻璃界面：取景、编辑器、图库
```

## 运行

- Xcode 26 或更新版本，iOS 26 真机（模拟器没有相机）
- 打开 `RefocusCamera.xcodeproj`，在 *Signing & Capabilities* 选择你的开发团队，必要时修改 Bundle ID
- 带双摄 / LiDAR 的机型可获得深度数据并启用“光圈”虚化；只有单摄的机型仍可使用焦点堆栈

## 注意

- 扫描 9 帧大约需要 1 秒，拍摄时请保持手机稳定（对齐能纠正轻微抖动，无法纠正明显的运动物体）
- 如果设备的虚拟多摄不允许手动设置镜头位置，会退回到广角镜头（此时没有深度数据）
